# US Accident Severity Prediction API

This FastAPI service exposes the existing trained US accident severity model.
It does not retrain or modify the model. The service applies the raw feature
engineering from `notebookc93255d60e.ipynb`, then calls the preprocessing
pipeline and classifier already stored in `accident_severity_model.joblib`.

## Model behavior

- Raw inputs: the 26 columns recorded in `model_details.json`.
- Engineered inputs: hour, weekday, month, year, and a street-based road type.
- Bundled preprocessing: numeric passthrough plus ordinal encoding for recorded
  categories and road type.
- Classifier: weighted histogram gradient boosting.
- Output mapping: classifier classes `0` through `3` map to severity levels `1`
  through `4`.
- Decision rule: multiply the four `predict_proba` scores by the saved
  multipliers `[3.0, 1.0, 2.0, 3.0]`, then choose the largest adjusted score.

The returned `model_scores` are the classifier's original `predict_proba`
estimates. The notebook states that they are not calibrated real-world
probabilities.

## Run locally on Windows PowerShell

From this project directory:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

Open Swagger UI at <http://127.0.0.1:8000/docs>.

## Endpoints

- `GET /health`: service and model readiness.
- `GET /model/info`: model contract, levels, score behavior, and saved metrics.
- `POST /predict`: one record.
- `POST /predict/batch`: `{"records": [...]}` with 1 to 1,000 records.
- `GET /docs`: interactive OpenAPI documentation.

## Postman example

Send this body as JSON to `POST http://127.0.0.1:8000/predict`:

```json
{
  "Start_Time": "2022-08-15 17:30:00",
  "Street": "I-95 N",
  "Start_Lat": 40.7128,
  "Start_Lng": -74.006,
  "Temperature(F)": 78.0,
  "Humidity(%)": 68.0,
  "Pressure(in)": 29.85,
  "Visibility(mi)": 10.0,
  "Wind_Speed(mph)": 8.0,
  "Precipitation(in)": 0.0,
  "Amenity": false,
  "Bump": false,
  "Crossing": false,
  "Give_Way": false,
  "Junction": true,
  "No_Exit": false,
  "Railway": false,
  "Roundabout": false,
  "Station": false,
  "Stop": false,
  "Traffic_Calming": false,
  "Traffic_Signal": false,
  "State": "NY",
  "Weather_Condition": "Fair",
  "Sunrise_Sunset": "Day",
  "Civil_Twilight": "Day"
}
```

Response structure:

```json
{
  "predicted_severity": 2,
  "model_scores": {
    "1": 0.000198,
    "2": 0.832586,
    "3": 0.133755,
    "4": 0.033461
  }
}
```

The values above are generated by the saved model for this example; they are
not hardcoded by the API.

All 26 keys are required. Values may be `null` where the notebook's model path
supports missing values. Unknown recorded categories are handled by the saved
ordinal encoder. Extra fields, malformed dates, invalid numeric types, and
invalid road flags return an HTTP 422 validation response.

## Tests

After installing `requirements.txt`, run:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

The tests cover artifact loading, health and model metadata, single and batch
predictions, null values, invalid and incomplete requests, the response shape,
the notebook decision rule, and agreement between the `.joblib` and `.pkl`
artifacts.
